# 信息架构与交互

## 原则
- **一份意图，两种视角。** "选一个 Skill → 指定给谁" 和 "选一个 Agent → 调整它有什么" 改的都是同一份 `rules`，界面上任何地方都没有第二份状态。
- **先草稿，后应用。** 所有开关只修改草稿。草稿和已保存配置不一致时，底部出现"N 处文件变更待应用"栏，⌘↩ 打开预览。预览就是计划本身：每条变更、带 diff、标出风险；做不到的事情列在"需要注意"里，并写明原因。
- **展示实际生效，而不只是配置。** 每个格子都在回答"这个 Agent 现在到底能不能看到它、通过什么途径"。

## 页面结构（侧栏）
```
Dashboard
Library
  Skills        列表 | 矩阵
  Profiles
Agents
  ● Claude Code   9      ← 直接列出每个 Agent，数字 = 实际加载的技能数
  ● Codex        14
  ● OpenCode     12
  ● Gemini CLI   11
Projects
  ▸ app-web
  + Add Project…
History
```

### Dashboard
- 每个 Agent 一张卡片：版本、实际加载的技能数、**常驻上下文 token 估算**（技能名+描述，加上加载的指令文件），以及问题数。点卡片进入 Agent 页。
- Health：断链、同名冲突、外部修改、其他工具的托管块、超过 32 KiB 等问题。
- 技能来源概览：库、共享源、各 Agent 目录里的本地文件夹、插件。

### Skills（资源视角）
- 列表行：名称、描述，以及一排 Agent 色点（实心 = 生效，描边 = 待变更）。可以把行**拖到侧栏的某个 Agent 上**，直接完成分配。
- 详情：
  - **"谁会用到"网格**：行是作用域（全局 + 各项目），列是 Agent。点格子切换；行尾菜单有 全部开 / 全部关 / 清除。
  - 格子的图标说明它是怎么到达这个 Agent 的：✓ 链接 · ▤ 共享目录 · ↳ 经由别的 Agent 的目录 · ↓ 来自全局 · ⊘ 被 Agent 自己的设置关闭 · ＋/－ 待变更（虚线框）。
  - "各 Agent 从哪加载它"：给出具体路径、链接目标和途径。
  - 问题：缺描述、名称不合规、嵌套 SKILL.md、同名目录。
  - SKILL.md 预览和编辑（保存时保留旧版本）。
  - "移入库"：把散落在别处的技能目录收编进库，原位置留一个链接，可撤销。
- **矩阵模式**：一屏显示 所有技能 × 所有 Agent，表头显示每个 Agent 的技能总数，可以只看已生效的技能。适合批量整理、给上下文瘦身。

### Agent 页（Agent 视角）
- 头部：版本、可执行文件路径、配置目录、"由 Kitfold 管理"开关、上下文用量条。顶部工具栏可以切换作用域（全局 / 某个项目）。
- **Skills**：按到达途径分组——链接进自己目录的 / 自己目录里的真实文件夹 / 共享目录 / 经由别的 Agent 的目录 / 项目技能 / 插件 / 被自己的设置关闭。每行都有同样的切换格子；可以从库里搜索添加，也可以直接拖进来。
- **Profiles**：开关列表，并说明会写到哪个文件。
- **指令文件**：按加载顺序列出，标明是否加载、是否为 Kitfold 写入目标、是否 fallback、是否符号链接、大小、还有谁在读、Kitfold 的块、其他工具的块。有外部修改的块直接给出"保留修改 / 覆盖"两个按钮；每个文件都能编辑（编辑完先看 diff 再应用）。
- **它怎么找技能**：扫描的目录（按优先级排列）、每个目录的角色和说明（附已验证 / 假设标记）、官方文档链接。

### Profiles
- 列表上显示分配给了哪些 Agent。
- 编辑器包括：
  - 名称、描述、order（多个 Profile 写进同一文件时的先后）；
  - 分配网格（作用域 × Agent，悬停显示会写到哪个文件）；
  - 附带的技能（标签形式）；
  - 正文：编辑 / 预览 / **对比**（和每个已部署的副本，或任意一个历史保存版本做 diff）。
- **组合**：一个 Agent 可以同时挂多个 Profile，每个占一个独立托管块，按 order 排列。
- **继承与覆盖**：在 Agent 页切到某个项目时，指令文件链会先列出全局文件，再列出项目文件，和 Agent 实际的拼接顺序一致。

### Projects
- 每个 Agent 在这个项目里的技能数（其中有多少是项目独有）和项目级指令文件。
- 项目级 Profile 网格，加上该项目的技能矩阵。

### History
- 每次 apply 或撤销都是一条记录，可以展开看具体操作和备份位置。撤销前会检查前置条件。

## 键盘
| 快捷键 | 动作 |
|---|---|
| ⌘K | 快速打开：搜索技能、Profile、Agent、项目和动作；↑↓ 选择，↩ 执行，Esc 关闭 |
| ⌘↩ | 预览并应用 |
| ⌘R | 重新扫描 |
| ⌘N / ⇧⌘N | 新建 Profile / 新建 Skill |
| ⌘1–4 | Dashboard / Skills / Profiles / History |
| ⌘S | 在编辑器里保存 / 预览 |
